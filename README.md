# E-Commerce Customer Churn Analysis

## Problem
Customer churn rate of 35.85% causing $489M in lost revenue

## Approach
- **Data:** 500K transactions, 50K customers, 45 months (2020-2023)
- **Tech Stack:** MySQL for ETL, Power BI for visualization
- **Analysis:** Multi-dimensional behavioral comparison across 9 segments

## Key Insight
Churned customers are statistically identical to active customers across ALL metrics:
- Avg Revenue: $27.2K (both groups)
- Avg Orders: 10 (both groups)  
- Return Rate: 40.4% (both groups)
- Repeat Rate: 99.98% (both groups)

**Conclusion:** Churn is a structural business problem, not behavioral

## Deliverable
3-page interactive dashboard following PAIRA framework:
1. Executive Overview (Problem + Impact)
2. Behavioral Drivers (Analysis + Insights)
3. Action Plan (Recommendations + Metrics)

## Business Recommendations
- Launch retention program targeting 55+ age segment ($300M at risk)
- Investigate external factors (competition, pricing, market conditions)
- Reduce dependency on Crypto payment users (lowest value, highest churn)
- Focus on post-purchase experience (since pre-purchase behavior identical).
